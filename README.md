# Blocos de Madeira
Jogo de peças que caem. A tela começa vazia e sobe uma fileira nova (com buracos) por baixo, bem devagar.
Quando uma linha some, os pedaços de peça que ficam soltos caem até bater no fundo ou em outra peça.
Controles: setas / espaço / P no computador, ou os botões na tela (toque no tabuleiro também gira).
Publicar: envie `index.html` para a raiz do repositório e ative o GitHub Pages.
